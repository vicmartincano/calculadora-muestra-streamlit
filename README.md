# Calculadora de tamaño de muestra

Aplicación Streamlit en español para calcular el tamaño de muestra de una población finita.

## Ejecutar

1. Instala dependencias:

```bash
pip install -r requirements.txt
```

2. Ejecuta:

```bash
streamlit run calculadora_muestra.py
```

La aplicación abre en el navegador y permite seleccionar población total, confianza, error, proporción esperada y tasa de respuesta.
